# Dhamodharan P. — Portfolio

Updated React + Vite portfolio with responsive layouts and refreshed professional content.

## Run locally

1. Extract this ZIP.
2. Open a terminal in the `ProjectPortfolio` folder.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Create a production build:

   ```bash
   npm run build
   ```

## Before publishing

- Add your latest resume PDF to `public/` and add a download link if you want a resume button.
- Replace the general GitHub profile links on project cards with the exact repository URL for each project.
- Add a live demo URL only when the project is deployed and working.
- Verify the Formspree form endpoint and submit a test message.
- Review the phone number and email displayed in the Contact section before making the site public.
